# PSION
**ПСИОН** (**П**рограмма **С**бора **И** **О**бработки **Н**овостей) - программа, которая позволяет отображать новости с сайта специально для заказчиков.

---

## Основная информация

Сервис решает задачу кейса «Новостная аналитика для принятия бизнес-решений»: руководителю крупной компании важна не сама новость, а её влияние на бизнес. ПСИОН:

- определяет контекст компании по обезличенным данным (отрасль, регион, продукты банка, контрагенты, ФТС);
- собирает новости из внешних RSS-источников;
- отбирает и ранжирует события, значимые для конкретного клиента;
- формирует интерпретацию: что произошло, почему это важно для компании, риски, возможности, действия, оценка банка, вывод AI;
- показывает результат в веб-интерфейсе.

> [!TIP]
> Выберите компанию в левой панели — лента событий справа перестроится под её профиль.

---

## Принцип работы

1. **Загрузка профиля.** Данные о юрлицах, физлицах и платежах читаются из CSV (`app/data_loader.py`).
2. **Профилирование.** `app/profiling.py` превращает сырые признаки в сигналы: `credit_exposure`, `foreign_trade`, `industry:IT` и т.д.
3. **Сбор новостей.** `app/news_parser.py` тянет RSS, классифицирует по тегам (`rate`, `it`, `sanctions`...).
4. **Матчинг и ранжирование.** `app/matching.py` сопоставляет теги события с сигналами клиента и считает `relevance_score`.
5. **Интерпретация.** Каждое событие получает блоки: что произошло, почему важно, риски, возможности, действия, оценка банка, вывод AI.
6. **Интерфейс.** FastAPI отдаёт HTML на `/`, JS-фронт обращается к API.

## Использование

### Требования

- Python 3.12+
- Docker (опционально, но рекомендуется)

### Локальный запуск (без Docker)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Mager2112/PSION.git
cd PSION

# 2. Создать и активировать виртуальное окружение
python -m venv hack
source hack/bin/activate  # Linux/macOS
# hack\Scripts\activate   # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Положить CSV-файлы в папку data/
# data/df_Uid_data_hack.csv
# data/df_Fid_Uid_link_hack.csv
# data/df_Uid_payment_hack.csv

# 5. Запустить сервер
uvicorn app.main:app --reload
## Скриншоты
## Изображения ##
```
### Запуск с Docker
```bash
docker build -t psion .
docker run -p 8000:8000 psion
```

### Язык и фреймворки
- Python 3.12
- FastAPI (версия из requirements.txt)
- Uvicorn (версия из requirements.txt)
- Pydantic (версия из requirements.txt)

### Библиотеки
- feedparser (версия из requirements.txt) — парсинг RSS
- requests (версия из requirements.txt) — HTTP-запросы (если используется)

### Данные
- df_Uid_data_hack.csv — синтетические обезличенные данные о юрлицах (предоставлены организаторами хакатона)
- df_Fid_Uid_link_hack.csv — синтетические обезличенные данные о физлицах (предоставлены организаторами)
- df_Uid_payment_hack.csv — синтетические обезличенные данные о платежах (предоставлены организаторами)
- Аналитические материалы Альфа-Банка (предоставлены организаторами)

### Внешние сервисы
- RSS-источники: ЦБ РФ, РБК, Интерфакс, CNews, TAdviser, Habr — публичные RSS-ленты, используются для сбора новостей.

### Смоделированные интеграции
- LLM-компонент: в текущей версии **не подключён**, интерпретация шаблонная (`_interpret` в `news_parser.py`). При подключении LLM будут использоваться только модели из разрешённого списка кейса.
- RAG по аналитике Альфа-Банка: **не реализован**, поле `bank_view` заполняется заглушкой.

### Демо-данные
- `app/demo_events.py` — синтетические демо-события для показа формата интерпретации.
